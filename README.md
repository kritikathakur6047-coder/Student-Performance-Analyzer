# Student Performance Analyzer Using Python

## Project Description
The Student Performance Analyzer is a Python-based application used to analyze students' academic performance. It calculates total marks, percentage, grades, and pass/fail status. It also displays a bar chart showing subject-wise marks.

## Features
- Enter student name and marks.
- Calculate total marks and percentage.
- Assign grades automatically.
- Display Pass or Fail status.
- Add multiple student records.
- Visualize subject-wise marks using a bar chart.
- Clear input fields.

## Technologies Used
- Python
- Tkinter
- NumPy
- Matplotlib
